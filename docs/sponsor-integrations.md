# Sponsor integration status

The standalone project preserves the adapter boundaries and local evidence for
Visa-oriented procurement UX, Nessie, Fetch.ai, Hyphenate-style finance
controls, Coinbase x402, Anthropic, Apify, CRS, and SpacetimeDB.

The offline demo explicitly uses local/mock behavior where external credentials
or a verified sponsor API contract is unavailable. Moving an adapter into this
repository does not constitute live integration verification.
