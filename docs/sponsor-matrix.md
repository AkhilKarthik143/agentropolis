## Evidence commands and limitations

`python3 -m pytest tests/test_external_adapters.py tests/test_llm_gateway.py tests/test_transport_fetch.py tests/test_sponsor_controls.py` passed **17 tests**. Adding `tests/test_stage2.py` passed **24 tests** total (three uAgents Python deprecation warnings). `python3 scripts/verify_fetch.py` passed one actual typed local uAgents exchange; `agentverse_verified=false` is printed explicitly. The broader backend suite and UI verification are reported separately.

Public/network adapters are opt-in building blocks, not an externally connected economy. No secrets were copied into source, no mainnet transfer was enabled, no sponsor registration or submission was performed, and no missing credential was represented as a successful provider call. See [required setup](USER_SETUP_REQUIRED.md) for costs, links and exact remaining evidence.
